# Portfolio Website – Shubhesh Jha

A personal portfolio website built using **HTML5 and CSS3** to showcase my skills, projects, education, and contact information.

## 🚀 Features

- Clean and modern dark-themed UI
- Responsive design for desktop, tablet, and mobile devices
- Sticky navigation bar
- Smooth scrolling between sections
- Hover effects and CSS transitions
- Interactive project cards
- Responsive typography using CSS `clamp()`
- Flexible layouts using Flexbox and CSS Grid
- Media queries for different screen sizes
- Custom focus styles for better accessibility

## 🛠️ Technologies Used

- HTML5
- CSS3
  - Flexbox
  - CSS Grid
  - Media Queries
  - CSS Transitions and Transforms
  - Pseudo-elements and Pseudo-classes
  - CSS `clamp()`

## 📂 Project Structure

Portfolio/

## 📱 Responsive Design

The website uses CSS media queries to adjust its layout for different screen sizes. CSS `clamp()` is also used to make heading sizes flexible within defined minimum and maximum limits.
